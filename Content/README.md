# Content directory

Create Unreal assets here through the Unreal Editor. The initial C++ prototype deliberately contains no binary uasset or umap files because those must be authored or generated by a compatible Unreal Editor.

Suggested first map: Content/Maps/LVL_Prototype.
Suggested Blueprint: Content/Blueprints/BP_SignalInteractable (child of ASignalInteractable) with a visible static mesh assigned.
